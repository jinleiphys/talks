# Using AI in Research: Lessons from FUSION

第五届机器学习会议培训班，2026-10-30。金磊。

90 分钟，中文讲述，kami 风格。33 页正文、4 页备用。
含 5 分钟验收练习与 5 分钟问答。每页有讲者备注、时间与转场。

## 文件

- `slides.md`：幻灯片与讲者备注的主文件。
- `using-ai-in-research.pdf`：静态版，展示各页最终内容。
- `using-ai-in-research-clicks.pdf`：点击展开版，适合讲解和练习的 PDF 回退。
- `speaker-notes.md`：按页整理的讲者稿。
- `task-template.md`：可复制的任务模板与练习答案。
- `examples/`：FRESCO 与 COLOSS 真实输入。
- `evidence/`：保存的验证记录、冷启动原始表与来源说明。
- `QA.md`：构建、渲染和冷读检查记录。

## 预览与演讲

```bash
npm run dev
npm run present
npm run build
npm run export
npm run handout
```

本机依赖安装在同步目录外，项目中 `node_modules` 是软链接。
转移项目时排除该软链接。新机器可按 package.json 安装依赖；也可直接使用 PDF 或 `dist/` 静态网页。
建议会前测试浏览器全屏、中文字体、翻页器与投影设备。

## 现场安排

- 0–40 分钟：真实输入、半径、质量、数值比较与验收练习。
- 40–65 分钟：SMASH 历史失败及本次实际执行的小反例。
- 65–75 分钟：安装审计、错误摘要、论文定位。
- 75–85 分钟：个人任务改写与研究判断边界。
- 85–90 分钟：问答。

第 4、18 页采用点击驱动的 Three.js 场景。方向键前进与后退。

默认使用保存的真实输入和验证记录，可以离线讲完。
没有在准备本讲时重新运行科学计算；实际执行了人工输出反例的轻量脚本检查。
第 14 页为验收练习，第 15 页展开复核顺序；第 30 页改写个人任务。
第 21–24 页为本次实际运行的输出检查反例，可按 evidence/parser-case/README.md 复现。
备用页分别讲随机模拟、评价术语、版本维护与演示回退。

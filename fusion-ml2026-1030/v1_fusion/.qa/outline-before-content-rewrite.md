# Using AI in Research: Lessons from FUSION

第五届机器学习会议培训班 · 2026-10-30 · 金磊
同济大学；中国科学院近代物理研究所南方核科学理论研究中心

## 讲座定位

90 分钟培训讲座。默认听众为有机器学习基础、未必熟悉核反应程序的研究生与研究者。中文讲述，中文主标题与英文副标题。Kami 风格。计划约 42 页正文，4 页备用，每页含讲者备注。

问题：AI 能完成越来越多研究操作，研究者凭什么接受它交回来的结果？
缺口：能运行、能复现与物理正确，需要不同的证据。
核心：给 AI 可执行的任务，同时给它明确的参考、验证方法、停止条件和交付记录。
证据链：半径约定的静默错误；同一散射问题的收敛与跨程序比较；冷启动安装审计；验证脚本的反例与修复传播；文献引用图的错误与纠正。
结论：把研究判断落实成能检查的证据，AI 才能成为可靠的执行者。
更高一层：任务自动化可以提高研究效率，问题是否值得回答、证据是否支持结论，仍需研究者判断。

## 结构和时间

1. 0–10 分钟：AI 进入研究工作之后，责任落在哪里（5 页）
   从一个看起来合理的输出开场；定义语言模型、工具、agent；对比回答与实际执行；分开运行成功、数值验证、物理判断；给出整场路线。
2. 10–25 分钟：FUSION 怎样把程序经验交给 AI（7 页）
   定义 FUSION；程序专用技能的构成；从已验证输入修改；安装、运行、解析与验证的依赖；两类参考及其边界；构建自己的最小技能；冷启动测试。
3. 25–45 分钟：走完一个真实计算（9 页）
   用普通语言介绍 n+90Zr、50 MeV 与总反应截面；明确计算任务；追溯势参数来源；半径约定及 ap=0；运行记录；收敛检查；统一质量约定；FRESCO 与 COLOSS 比较；区分数值符合与物理结论。
4. 45–65 分钟：验证器也会说错话（9 页）
   定义误报通过；用缺文件、缺行、非有限值和异常退出构造反例；SMASH 五轮修复的案例；修复引入错误；审计相邻版本；冷启动四类结果；旧摘要如何传播错误；文献引用图的错误链接；返回原文与权威元数据。
5. 65–80 分钟：把这些经验用到自己的项目（7 页，含 5 分钟练习）
   写可检验的任务；控制资源和权限；记录输入、版本、输出与失败；第二个模型的独立性边界；练习“这份结果能接受吗”；公开答案与验收条件；一个可以直接使用的任务模板。
6. 80–90 分钟：从执行效率回到研究问题（5 页，含 5 分钟问答）
   已知答案适合验证工具；未知答案才可能产生研究发现；启动前写出可被推翻的问题；收束两条结论；资源页与问答。

演示默认使用已保存的真实输入、输出与点击展开的流程，另备现场操作说明，保证离线可讲。练习页先展示有缺陷的交付，再揭示缺少的证据。

## 术语清单

| 术语 | 幻灯片处理 |
|---|---|
| AI / 人工智能 | 标题保留；正文聚焦语言模型参与研究操作 |
| LLM / 大语言模型 | 首次出现写全称并定义 |
| agent / 智能体 | 定义为调用工具、观察结果、继续执行任务的工作系统 |
| tool / 工具 | 定义为读写文件、搜索、运行程序等可执行操作 |
| skill / 技能 | 定义为程序专用操作说明、示例与验证脚本的组合；不是模型权重训练 |
| FUSION | 本项目名称；首个介绍页说明用途；英文展开以仓库为准 |
| benchmark / 基准 | 已知参考结果、适用配置和比较容差 |
| tolerance / 容差 | 验收允许的数值差；不代表物理模型的不确定度 |
| cold-start / 冷启动 | 在没有已安装依赖或缓存的环境测试安装路径 |
| false pass / 误报通过 | 结果缺失或运行失败时，验证脚本仍报告通过 |
| adversarial test / 反例测试 | 有意制造错误，检查验证器能否拒绝 |
| convergence / 收敛 | 加密数值设置后，目标量变化足够小 |
| cross-code comparison / 跨程序比较 | 同一方程、参数及约定下比较独立求解程序 |
| FRESCO / COLOSS | 分别介绍为两个采用不同数值方法的散射求解程序 |
| SMASH | 首次出现说明为强子输运程序；本讲只讨论它的验证脚本 |
| KD02 | 首次出现说明为 Koning–Delaroche 核子光学势参数化 |
| optical potential / 光学势 | 用于描述核子与原子核散射及通量损失的有效相互作用 |
| n+90Zr / 50 MeV | 定义为 50 MeV 中子入射锆-90；明确实验室能量 |
| sigma_R / 总反应截面 | 首次出现定义；符号用公式或图例，单位 mb 同页解释 |
| mb / 毫靶恩 | 截面单位；首次出现注明 1 mb = 10⁻³ barn |
| r0、R、Ap、At、ap=0 | 只在半径约定页出现，同页定义；ap=0 是输入开关 |
| physical / integer masses | 真实核质量 / 整数质量近似；比较页解释 |
| arXiv / DOI | 首次出现说明为预印本库 / 文献持久标识 |
| INSPIRE | 首次出现说明为高能与核物理文献元数据服务 |
| citation graph / 引用图 | 定义为论文之间的引用关系网络 |
| accuracy / precision | 准确度 / 精密度分别定义，不混用 |
| AGENTS.md / SKILL.md | 首次出现说明为项目规则文件 / 技能说明文件 |
| Git / commit | 如需使用，说明为版本控制 / 可定位的版本；正文优先说“版本” |
| 内部研究线、阶段名、wiki 路径 | 不放进幻灯片 |
| CDCC、DWBA、PINN、HMC 等 | 主线不使用；本讲不要求核反应或贝叶斯算法背景 |

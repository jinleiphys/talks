# 现场演示提示词（原文，直接粘贴）

## 版本一：开场（一句话版，故意不写约定）

用 Julia 写一个程序：n-p 的 s 波散射，方势阱，半径 R = 2.0 fm。
1. 调势阱深度 V0，使氘核结合能为 2.2246 MeV；
2. 用 Numerov 方法算 0 到 50 MeV 的相移 δ0(E)；
3. 和解析解比较，报告最大偏差；
4. 输出三重态散射长度 a_t，画出 δ0(E)。

## 版本二：写清楚的任务（第 2b 段）

目标：同上。
约定：ħc = 197.327 MeV fm；约化质量 μ = m_n m_p /(m_n + m_p)，m_n = 939.565，m_p = 938.272 MeV。
     相移取 Levinson 定理的分支，δ0(0) = 180°（有一个束缚态）。
验收：(a) Numerov 与解析解最大偏差 < 0.01°，并给出步长减半后的偏差；
     (b) 独立对照：a_t 与实验值 5.42 fm 比较，报告相对差。
交付：程序文件、运行命令、终端原始输出、δ0(E) 图；改动只限 demo/ 目录。
遇到以下情况停下来问我：结合能拟合不收敛，或 a_t 与实验差超过 5%。

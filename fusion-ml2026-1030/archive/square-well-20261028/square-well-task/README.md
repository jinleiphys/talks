# 任务：n–p 方势阱的 s 波相移

这是课上现场演示的任务。把这个文件夹当作你的项目目录，在里面启动 agent（Claude Code、Codex 或 OpenCode），然后按 `PROMPTS.md` 的三条提示词依次发送。

## 物理设定

- 中子和质子之间是一个吸引方势阱：r < R 时 V(r) = −V₀，r ≥ R 时 V = 0。
- 半径 R = 2.0 fm。
- 调整深度 V₀，使这个势阱的唯一 s 波束缚态的结合能等于氘核结合能 B_d = 2.224575 MeV。
- 用这个 V₀ 计算 s 波相移 δ₀(E)，E 是质心系能量，取 0.1、1、5、10、20、50 MeV。
- 两种方法都算：径向方程的 Numerov 数值解，和方势阱的解析解。

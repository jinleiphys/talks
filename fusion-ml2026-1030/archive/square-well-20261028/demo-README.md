# 方势阱进阶材料

当前入门课程请从 [intro/README.md](intro/README.md) 开始。以下是备用物理验证案例，不是本次开场演示；其旧版资料包已归档。

这套材料支持“明确任务、复现计算、判断证据”三个课堂动作。

## 怎么开始

本案例保留在完整报告目录的 `demo/` 中。进入完整报告目录，在终端执行：

```bash
julia demo/square_well.jl
```

需要已安装 Julia。本次参考运行使用 Julia 1.11.4，不需要第三方 Julia 包。没有 Julia 的同学先阅读 `demo/reference-output.txt`，仍可完成全部纸笔练习。现场生成不成功时，讲者也使用这份离线参考实现。

程序会输出比较表，并重新写入 `demo/phase_shift.csv`。请在自己的副本中运行。代码中的两组计算分别使用正确约化质量和人为设置的错误核子质量；错误算例是教学反例，不是某次 AI 回答记录。

## 预期结果及范围

- 正确约化质量：V0 = 36.567 MeV，a_t = 5.356 fm。
- 错误核子质量：V0 = 20.986 MeV，a_t = 4.105 fm。
- 六点数值对解析相移的最大差分别约 0.0059°、0.0037°。
- 六点为质心系 E = 0.1、1、5、10、20、50 MeV；步长 0.0002 fm，匹配半径约 10 fm。
- CSV 作图网格为 0.05 至 50 MeV 的 120 点。六点最大差不是连续能区的误差上界。
- 这些比较检验特定设置的数值求解，不构成模型对实验的验证。

本课不进行实验数据比较。研究中使用实验值必须另查原始测量及误差。

## 练习与使用顺序

1. `demo/worksheet.md`：三次课堂练习和离堂题，末尾有参考点评。
2. `demo/prompt.md`：初始任务、完整任务和课后追问。
3. `demo/square_well.jl`：会前参考实现。
4. `demo/reference-output.txt`：2026-10-20 实际运行的完整终端输出。
5. `demo/phase_shift.csv`：对应的数据表。

参考实现同时打印步长、匹配半径和束缚态匹配残差。它是用于离线回退的会前实现，不是现场智能体生成记录。

课后半径扫描尚未执行。先复制程序到独立目录，维持最浅单 s 波束缚态分支，每个半径重新拟合，并为新配置检查结果。

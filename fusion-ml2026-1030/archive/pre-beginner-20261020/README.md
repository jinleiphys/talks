# 用 AI 做科研：从一个问题到一个可信的结果

第五届机器学习会议培训班，2026-10-30。金磊。90 分钟，中文，kami 视觉风格。

当前入口为 `slides.md`，30 页正文、4 页备用。旧版本保存在 `archive/pre-restructure-20261020/`，更早的 FUSION 版本保留在 `v1_fusion/`。

## 教学目标

学生能够把一个小任务交给 AI，从文件复现结果，并说明每项检查究竟排除了哪类错误。全场用 n-p 方势阱串起“明确任务、执行与复现、判断证据”。

| 时间 | 内容 | 学生动作 |
|---|---|---|
| 0–6 分钟 | 学习目标与物理问题 | 分清拟合量与预测量 |
| 6–16 分钟 | 明确任务 | 练习一：补全物理约定 |
| 16–32 分钟 | 执行与复现 | 跟踪命令、文件和一个输出数 |
| 32–54 分钟 | 判断证据 | 练习二：两份自查均通过时，设计下一项检查 |
| 54–67 分钟 | 迁移方法 | 老程序、流程保存、FUSION、文献写作 |
| 67–79 分钟 | 自己的任务 | 练习三、同桌互评、离堂题 |
| 79–85 分钟 | 回顾与任务点评 | 带走一份可执行的任务 |
| 85–90 分钟 | 问答 | 讨论实际任务的障碍 |

三条带走的问题：运行前哪些选择需要我定？运行后检查排除了什么错误？得到结果后它支持我说到哪一步？

每页的讲者备注含主旨、图示说明、讲法、时间和转场。真正的静默练习时间已经排入备注，不要用讲解填满。

## 发给学生

`student-materials.zip` 含静态讲义、参考程序、实际输出、数据表、完整提示词和练习单。解压后先看根目录 README.md，再在该目录执行 `julia demo/square_well.jl`。

现场智能体演示等待不超过 60 秒。网络或生成不成功时，明确切换到会前参考程序，不能将它冒充现场生成结果。

## 证据边界

参考程序为单 s 波方势阱教学模型。数字经 Julia 1.11.4 实际重跑；错误质量分支为人为设置的反例。相移最大差只覆盖六个指定能量点。解析解吻合检查数值求解，不构成实验验证。课后半径扫描没有执行。

冷读审查由同一模型家族的独立上下文读者完成，不能称为跨模型科学验证。验证记录见 QA.md。

# 课堂提示词

## 练习一：尚未补全的任务

用 Julia 写中子与质子的方势阱 s 波散射程序。
半径 2 fm，调势阱深度，拟合结合能 2.224575 MeV。
用 Numerov 算 0 到 50 MeV 的相移，与解析解比较。
输出散射长度，并画图。

学生先写三条补充要求，并说明每一条避免什么歧义。

## 现场执行：完整任务

在当前独立练习目录完成以下计算。

问题与设定：
- 教学模型：吸引方势阱，保留 n-p 三重态 s 波，省略张量耦合。
- V(r) = -V0（r < R），V(r) = 0（r >= R）；R = 2 fm。
- 取 c = 1，使用 MeV、fm；hbar*c = 197.3269804 MeV fm。
- mn = 939.56542 MeV，mp = 938.27209 MeV；相对运动使用 mu = mn*mp/(mn+mp)。
- 用结合能 B = 2.224575 MeV 定 V0；选择最浅的、仅含一个 s 波束缚态的分支。
- E 是质心系动能。用 Numerov 算 E > 0 的散射相移，范围 0.1 到 50 MeV。
- 原点为正则边界；在势阱外匹配自由散射波。相移取连续分支，E 趋于零时为 180 度。
- 零能单独用极限处理，输出三重态散射长度 a_t，注明它的求取方法。

检查：
- 在 E = 0.1、1、5、10、20、50 MeV 六点，与同设定的方势阱解析解比较。
- 逐点报告相移与绝对差，六点最大差小于 0.01 度。
- 报告径向步长、匹配半径、束缚态匹配残差；数值失败时保留输出并说明。
- 核对约化质量来自两体相对运动，而不是仅让两个程序复制同一变量。
- 区分数值比较、结合能拟合和其他模型输出；不把解析解吻合写成模型获得实验验证。

交付与边界：
- Julia 源码、运行命令、原始终端输出、逐点 CSV 数据表。计算只用标准功能，避免临时安装大量依赖。
- 第一轮先交上述文件，课堂结束后再处理画图；作图必须使用本机 nature-figure 技能。
- 只在当前练习目录工作，不修改其他项目、参考文件或实验数据。
- 拟合无解、存在多个分支或需要改变物理设定时，先报告并暂停。

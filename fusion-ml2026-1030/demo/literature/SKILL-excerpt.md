# literature-search：课堂中文节选

这是已在使用的 literature-search 技能的教学节选，用来讲解结构，不是完整可安装版本。

```yaml
---
name: literature-search
description: 搜索并核实科学文献；查论文、DOI 或生成 BibTeX 时使用。
---
```

1. 先用 literature-wiki 查已有文献笔记。笔记提供候选题目或标识符，不能代替数据库核实。扩展相关文献时，先收集已读论文的参考文献。
2. 有明确 DOI 或 arXiv ID，直接取数据库记录；只有模糊描述，先搜索候选，再读取完整记录。
3. 用 INSPIRE、CrossRef 或 arXiv 等工具获取记录。引用中的作者、题目、年份、卷页和标识符必须来自本次返回的字段，不凭记忆补齐。
4. 核对记录是否符合所找论文。多个候选无法区分时，列出差异；网络失败或无匹配时，说明发生了什么。查不到不代表论文不存在。
5. 缺字段标 `UNVERIFIED`。未核实的条目留在核对报告，不当作正式引用输出。已有笔记与数据库不一致时，报告差异。
6. 输出 BibTeX、记录链接和检索日期。每条引用都能回到提供字段的记录。

原技能还附有 `scripts/verify_doi.py` 等查询脚本，以及 `references/` 下的接口和输出格式说明。

课堂讨论：如果把第三条删掉，只留下“不要编造”，智能体还知道该从哪里取字段吗？如果查库失败，输出应该是什么？

技能文件给出操作规程；智能体需要实际加载它并调用工具。核实书目信息之后，判断一篇论文是否支持某个结论，需要另行阅读原文。

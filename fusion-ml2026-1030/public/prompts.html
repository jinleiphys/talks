一、参考文献核对：加一份规程，结果有什么不同？

同一个 AI，做两次。第二次先开一个新对话。网页版请关掉联网搜索。

第一轮：直接问记下它的结论：哪几条它说有问题？

第二轮：先给规程，再问新对话。规程和题目已经拼好，复制一次即可。
核对参考文献时，遵守以下规程：
1. 不凭记忆下结论。没有查到原始记录的条目，一律标 UNVERIFIED，不许说“正确”。
2. 每条逐个字段核对：作者及顺序、题目、期刊、卷、起始页或文章号、年份。
3. 每个字段写明依据：查了哪个数据库，记录里写的是什么。
4. DOI 能打开不算通过，要确认打开的就是这一篇。
5. 发现不符，写出原文和记录各是什么，不自行“修正”。
6. 最后给一张表：条目号、结论（正确 / 有误 / UNVERIFIED）、依据。

二、方势阱：让 agent 写、跑、画、交

需要 agent（Claude Code、Codex 或 OpenCode）。新建一个空文件夹，先把任务说明存成 README.md，在这个文件夹里启动 agent，然后依次发送三条提示词。

任务说明存成文件夹里的 README.md
# 任务：n–p 方势阱的 s 波相移

## 物理设定
- 中子和质子之间是一个吸引方势阱：r < R 时 V(r) = −V₀，r ≥ R 时 V = 0。
- 半径 R = 2.0 fm。
- 调整深度 V₀，使这个势阱的唯一 s 波束缚态的结合能等于氘核结合能 B_d = 2.224575 MeV。
- 用这个 V₀ 计算 s 波相移 δ₀(E)，E 是质心系能量，取 0.1、1、5、10、20、50 MeV。
- 两种方法都算：径向方程的 Numerov 数值解，和方势阱的解析解。

## 常数
- ħc = 197.3269804 MeV fm
- 中子质量 m_n = 939.56542 MeV
- 质子质量 m_p = 938.27209 MeV
- 氘核结合能 B_d = 2.224575 MeV

## 约定
- 用 Python 3，可以用 numpy 和 matplotlib。
- 新文件放在当前目录，结果放进 results/。

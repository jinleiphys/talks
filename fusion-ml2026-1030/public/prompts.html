一、参考文献核对：加一份规程，结果有什么不同？

同一个 AI，每次都开一个新对话。第一轮关掉联网搜索；第二轮关联网、开联网各跑一次。

第一轮：直接问记下它的结论：哪几条它说有问题？

第二轮：先给规程，再问新对话。规程和题目已经拼好，复制一次即可。
核对参考文献时，遵守以下规程：
1. 不凭记忆下结论。没有查到原始记录的条目，一律标 UNVERIFIED，不许说“正确”。
2. 每条逐个字段核对：作者及顺序、题目、期刊、卷、起始页或文章号、年份。
3. 每个字段写明依据：查了哪个数据库，记录里写的是什么。
4. DOI 能打开不算通过，要确认打开的就是这一篇。
5. 发现不符，写出原文和记录各是什么，不自行“修正”。
6. 最后给一张表：条目号、结论（正确 / 有误 / UNVERIFIED）、依据。

二、现场演示：一句话，从光学势到实验数据

课上我用 Claude Code 加 FUSION 的 skill 现场跑的就是这一句。也可以原样贴进网页 AI，比一比两边交回来的东西。

现场演示的那一句在一个空文件夹里启动 agent 后发送
用 KD02 光学势算 p + 208Pb 30 MeV 的弹性散射角分布（对卢瑟福之比），和 EXFOR 里的实验数据画在一张图上，用 Python 画图，存成 results/p208pb_30MeV.png。告诉我用了哪组实验数据，以及你做了哪些检查。

FUSION 的 skill：github.com/jinleiphys/FUSION。不装 skill 也能跑，看看差在哪里。

三、让 skill 核实一篇论文

在装了 FUSION 的 agent 里发送。它会去 CrossRef 取原始记录，交回三个文件：原始记录、BibTeX、核对说明。

核实一个 DOI看它查了哪个库、存下了什么
用 literature-search 核实 DOI 10.1103/PhysRevC.97.011601。把数据库的原始记录、BibTeX 和核对说明都存下来，查不到的就空着，别自己补。

四、读一篇新论文，找合作机会

先从 arXiv 下载一篇论文放进 paper/ 目录，再在这个目录里启动 agent。“个人 wiki”换成你自己的笔记或论文列表即可。

新论文 + 两份 wiki推测和合作建议都是它的猜测，靠不靠谱由你判断
paper/ 里是我刚从 arXiv 下载的论文。先读原文，再查 arXiv wiki，找这个组以前的文章，梳理他们一直在研究什么，推测下一步可能做什么，并列出支持推测的文献。再查我的个人 wiki，只用我已发表的论文和公开代码，找双方可以合作的问题。每条都注明出处（arXiv 号或我的论文）。

五、回去做一个对照

选你课题里一个常用程序，同一句话问两次：一次什么都不给；一次先给它一份核对过的输入和一个已知结果。比一比两次交回来的东西。
